- **Subagent read-only/depth-1 is an ALLOWLIST, not a destructive-flag check:** `Tools.dispatch` rejects a tool when `context.allowedTools` is set and the name isn't in it. A destructive-flag check would NOT work â€” `dispatch_subagents` is itself `destructive=false`, so only an allowlist (the 5 read tools) blocks both writers AND nesting. - **Compaction rollback:** the abort/cancel rollback used an absolute message-count `snapshot`, but `Compactor.compact` shrinks the array â€” so AFTER a compaction the rollback must instead ensure the history ends on an assistant turn (the `compacted` flag + `rollback()` in `AgentLoop`), NOT count-truncate (which silently no-ops below the snapshot). `compact()` also validates the rebuilt history (`MessageUtil.isValidHistory`) before installing â€” a malformed kept tail â†’ refuse, never ship a guaranteed 400.
- **Task-list rollback in lockstep:** `update_tasks` mutates `deps.taskList` IN PLACE and the panel re-renders mid-turn, so on a non-clean exit the loop must restore the taskList alongside the conversation (`taskSnapshot` captured at Send start; restored in `rollback()` AND the `AgentLoop.send` outer failsafe), else the panel (and a cancel-path save) desyncs from the rolled-back history + persisted blob. The iteration-cap path does NOT roll back (keeps progress, resumable), so it keeps the checklist too. `update_tasks` is parent-only: not in the subagent `READ_ONLY` allowlist, and children's tool context carries no `taskList`.
- **Empty JSON objects:** Roblox `HttpService:JSONEncode({})` emits `[]`, but Anthropic needs a
  tool_use `input` to be an OBJECT. A no-arg tool call (capture / get_output with no args) decodes to
  an empty table and round-trips to `[]` â†’ 400 `tool_use.input: Input should be an object`. Fixed
  generically in `Anthropic.encodeBody` (sentinel-string swap â†’ splice back to `{}`); don't reintroduce
  a raw `JSONEncode(body)` for the request body. Verified against the live API ([] fails, {} 200s).
  **(2026-06-20) The SAME trap also bites tool DEFINITIONS:** a no-arg tool's `input_schema.properties =

  `capture`, tool 7 â€” and since the tools array rides EVERY request, this broke all of them). `encodeBody`
