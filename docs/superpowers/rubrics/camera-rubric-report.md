## Completeness — all five required killer systems covered
Factory completeness critic: COMPLETE and ABOVE THE MEAN, 5/5 killer systems, plus a load-bearing
architectural foundation most camera rubrics omit (the render-bind ownership contract).

1. **Context-driven camera state machine** → `camera-context-driven-mode-state-machine` (good): ≥3 modes
   each owning FOV/distance/offset/sensitivity, PARAMETER-blended transitions (not CFrame-swap).
2. **Spring-damped follow + look-ahead** → `camera-framerate-independent-spring-follow-lookahead`
   (exceptional): dt-correct smoothing (1−f^dt / 1−exp(−k·dt) / damped-spring), velocity look-ahead + settle.
3. **Reactive FOV + trauma shake** → `camera-reactive-fov-and-trauma-shake` (exceptional): context-tweened
   FOV band + trauma² Perlin-noise rotational shake composed additively over the follow.
4. **Collision/occlusion-aware framing** → `camera-collision-occlusion-aware-framing` (exceptional):
   filtered focus→camera raycast pull-in + target occlusion handling + over-the-shoulder offset/side-swap.
5. **Lock-on + cinematic composition** → `camera-lockon-cinematic-composition` (exceptional): composed
   dual-subject lock-on (behind-player-along-axis) + a CFrame/Bezier cutscene system distinct from gameplay.
