## Completeness — all five required killer systems covered
The completeness critic returned COMPLETE on all five mandated killer systems, each owned by a dedicated
criterion and reinforced by others:

1. **Modern Audio API spatial wiring** → `audio-modern-graph-spatial-wiring` (baseline): names the exact
   AudioPlayer → Wire → [effects] → AudioEmitter → AudioListener → AudioDeviceOutput chain, the #1 trap
   (a node with no outgoing Wire is silent), and the legacy equivalent (Sound on Attachment + tuned
   RollOffMode/min/max). Reinforced by `audio-client-predicted-listener-placement`,
   `audio-directional-volumetric-emission`.
2. **Curated library use with layered + randomized variation** →
   `audio-curated-library-variation-de-repetition` (good): role-matched clean-license assets AND a 4–8
   clip pool + per-play pitch/volume jitter (kills the machine-gun artifact).
3. **Dynamic mixing bus** → `audio-mixing-bus-hierarchy-gain-staging` (baseline) +
   `audio-sidechain-ducking-dynamic-mix` (good): Master→{Music,SFX,Ambience,UI,Voice} bus tree with
   neutral gain staging, plus a sidechained AudioCompressor (Input=music, Sidechain=voice/SFX) and an
   AudioLimiter master ceiling.
4. **Environmental audio** → `audio-environmental-reverb-eq-zones` (exceptional): one shared-bus
   AudioReverb retuned per zone + raycast EQ occlusion (the both-ends AcousticSimulationEnabled gotcha
   is called out).
5. **Event-synced + adaptive audio** → `audio-event-driven-source-bound-playback` (good) +
   `audio-adaptive-stem-layered-music` (exceptional): marker-synced one-shots emitted from the moving
   source, plus 4–8 sample-aligned looping stems on AudioFaders cross-fading by game state.

Two more criteria round out the soundscape: `audio-interaction-group-isolation`,
`audio-seamless-loop-craft`, and `audio-layered-ambience-bed-randomized-oneshots`.
