## Acceptance — PASSED (independent rubric-blind verify), with a method note worth recording
- **Floor rejection:** mean 0.000 (the default blocky avatar fails all 16).
- **Criteria validity:** **0 of 16 killed** — every skeptic returned *keep* with a concrete shipped
  example (Roblox "Beyond the Dark", DOORS, Team Fortress 2, Brookhaven, Arcane Odyssey, Bee Swarm).
- **Great side:** a first rubric-blind expert build scored **0.632** (under the 0.70 bar). Diagnosis from
  the per-criterion breakdown: the 4 majority-FAILs were all **art-direction** criteria (palette+value,
  theme through-line, face treatment, focal/detail hierarchy) while the **systems/pipeline** criteria
  passed — because the expert build's API hint was technical-only (HumanoidDescription/SurfaceAppearance/
  MeshPart/Motor6D), so the rubric-blind expert wrote a rig-heavy doc and under-specified art direction.
  Re-running with a **balanced** hint (technical **+** art-direction dimensions a real character expert
  delivers: palette, theme, faces, focal hierarchy, silhouette, cast cohesion) → **great 1.000, gap 1.000,
  0 killed → PASS**. The honest read sits between the two runs; what is robust across both is that the
  floor scores 0, every criterion is skeptic-validated as real, and a *complete* expert build clears the
  bar easily. **Method lesson (banked):** the rubric-blind verify is sensitive to expert-build COMPLETENESS
  — for multi-faceted domains, the `apiSurface` hint must cover the full surface (here: engineering *and*
  art direction), or the great side under-reads.
